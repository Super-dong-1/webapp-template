# 网页小应用模板

这是做网页小应用的起点。每次做新应用时，从这个模板复制一个新仓库即可。

## 做一个新应用的步骤

1. 在本仓库页面点绿色的 **Use this template** → **Create a new repository**，给新仓库起个名字（用英文小写字母和短横线，比如 `my-todo-app`）。
2. 把 AI 写的网页代码粘贴进来：打开 `index.html` → 点铅笔图标编辑 → 把原来的内容全选删除 → 粘贴 AI 给的代码 → 点 **Commit changes** 保存。
3. 样式和脚本可以分别放到 `css/` 和 `js/` 文件夹，图片放到 `images/` 文件夹。

## 网上访问地址

每个仓库开启 Pages 后，会得到一个网址，规则是：

`https://super-dong-1.github.io/仓库名/`

比如仓库叫 `my-todo-app`，网址就是 `https://super-dong-1.github.io/my-todo-app/`。每次点 Commit 保存后，等一两分钟刷新网址就能看到更新。
